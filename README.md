
# C-DataStructs

A comprehensive **C library of generic abstract data structures**, designed for learning and practical use.  
This project is a personal learning repository to explore **data structures in C**, including linked lists, stacks, queues, trees, hashmaps, and graphs.

## Project Goals

- Implement the most common and generic abstract data structures in C.
- Provide clear and modular code that can be reused and extended.
- Include examples and tests for each data structure.
- Learn best practices in C programming, memory management, and library design.
